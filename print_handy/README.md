# Home Assistant App: Print Handy

Bambu Handy for every printer. Drop a model link in chat, approve it, and Print Handy slices, prints and watches it.

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

This app runs the published [Print Handy](https://github.com/catduckgnaf/print-handy) image inside Home Assistant OS, and tracks its releases automatically. Pair it with the [Print Handy integration](https://github.com/catduckgnaf/ha-print-handy) to put every printer in Home Assistant.

See the **Documentation** tab for setup.
